# 术语表

> 更新日期：2026-10-15。
>
> 本文统一叫法。规则本身在各篇正文，本表只防止同一种东西写出两个名字。缩写可以出现在口头说明里，正文优先用中文。

| 术语 | 本仓库的叫法 | 不要写成 |
| --- | --- | --- |
| POS | 门店交易和店务触点。含收银、核销、代客下单、要货收货盘点、交班日结 | 中央OMS、进销存中台、财务系统 |
| 中枢 | 锁库、路由、业财所在的自研一侧。叙事里包括中央OMS、逻辑库存和业财编排 | 把POS说成中枢。ERP一期还不包含中央OMS和POS，见[待对齐事项A03](12.待对齐事项.md) |
| 中央OMS | 全渠道订单清洗和四维路由。四维是地址就近、运费最优、时效优先、库存充足 | POS里的一个菜单 |
| 逻辑库存 | 可售、锁定、在途的记账。门店微仓和代销仓的可用量以它为准 | POS本地库存 |
| 门店微仓 | 直营体验店的库存位置，货权在强盛 | 区域仓的库位。库位在WMS |
| 代销仓 | 加盟店的库存位置，记在强盛账上，加盟商是保管人 | 加盟商买断库存、加盟商的仓库编码体系 |
| 直营门店 | 强盛自己经营的体验店 | 供应商的送货对象。门店不向工厂下单 |
| 加盟门店 | 加盟合作的体验店。模式为代销 | 联营门店、扣点、商场对账。本仓库没有联营门店 |
| 代销 | 售出前货权在强盛。加盟要货是调拨，不产生货款 | 买断、先款后货、信用额度 |
| 营业款归集 | 加盟门店向顾客收款，再经与总部的结算回到强盛 | 门店不再经手收款。商户号仍见【待确认-16】 |
| 应缴营业款 | 中枢按加盟店营业日生成的应上缴金额。不含线上已付、只到店履约的订单 | 日结单本身，也不是加盟结算单 |
| 加盟结算单 | 按周期汇总分成或返点、履约佣金、冲回和扣项 | POS里由店员填写的金额 |
| 履约佣金 | 加盟店完成自提核销或门店代发后记给该店的服务报酬。规则见【待确认-20】 | 线上订单的营业额 |
| 小程序 | 顾客下单、选自提门店、出示提货码的触点 | POS的页面。是否与POS同一项目见【待确认-45】 |
| 提货码 | 中枢在锁定成功之后生成的动态码 | POS重新编的销售单号 |
| 核销 | 到店核对提货码并回传，使中枢完成扣减 | 锁库。锁库发生在下单时 |
| 代客下单 | 本店无货时，导购发起、由OMS路由的单据。必须带门店和导购工号 | 发货指令、工作群补货 |
| 进店销售 | 顾客在店里成交并支付 | 小程序自提。自提的钱通常已经在线上收过 |
| 交班 / 日结 | 班次核对，以及营业日封账 | 会计凭证 |
| 要货单 | 门店向中枢申请补货 | 采购订单。采购订单在SRM |
| 退仓 | 门店把货退回区域仓。加盟店的残次和滞销也走这里，不返货款 | 销售退货给消费者 |
| 主数据平台 | 阶段5叙事里SKU、客户、组织的源头，单向分发到POS | ERP一期已经上线的系统。时点见[待对齐事项A09](12.待对齐事项.md) |
| 金蝶 | 金蝶云·星空。法定核算和总账 | 门店开单入口 |
| 支付通道 | 微信、支付宝、银联或聚合服务商。具体哪一家见【待确认-40】 | 金蝶的收款单 |
| 商场报送 | 直营店租约要求时，把销售数据交给商场 | 联营结算、扣点 |
| 序列号 / SN | 按商品采集的单品编号 | 已经贯穿ERP和WMS的库存批次。批次规则尚未因此定稿 |
| 导购工号 | 业绩归属的主键 | 登录名。两者可以不同 |
| Code-Name | 编码加一个空格再加名称的展示方式 | 把名称拼进单号或接口主键 |
| 指标平台 | 阶段5固化GMV、净销售额、毛利率等算法的地方。门店利润含装修折旧在这里算 | POS报表里的净利 |
| 观远BI | 阶段5叙事里的经营分析工具，从ERP和金蝶取数 | POS内的第二套利润 |

ERP单据前缀、关闭和超量的含义，以ERP仓库为准，不在本表改写。采购订单的创建方向以[待对齐事项A04](12.待对齐事项.md)为准。
