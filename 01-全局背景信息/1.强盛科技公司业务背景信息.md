### 1.3 门店在整个生意里的位置

产品中心负责选品和设计，成品向代工厂采购，再卖到跨境、国内电商、独立站、B2B和后来的门店。采购订单在SRM创建，推给ERP，再推给仓库。这条链路不经过POS，见[待对齐事项A04](12.待对齐事项.md)。

门店卖的是已经入库的成品。体验、收银、到店核销和微仓店务发生在店里。可售数量、把订单派到哪一个仓或哪一家店、销售结果如何进财务，都不在店里的系统里另做一套。

## 二、线下触点的三次变化

### 2.1 阶段3（2016至2018年）：档口关掉，品牌店还没开

2016年注册QS-Tech之后，华强北展示档口年内关停，团队转入出海、电商和大客户。国内线下剩下的是30余家地市级总代理，以及他们覆盖的分销门店和维修店。那是批发网络，不是强盛自己的体验店。

这一阶段被明确记下来的缺口是：线下零售触点完全归零，没有线上线下一体化。POS不是在这一阶段立项的。

### 2.2 阶段4（2019至2022年）：后台收了主干，店仍然是空白

阶段4把计划、逻辑库存、深圳主仓作业和供应商协同收进自研后台，前台继续用领星和聚水潭，金蝶退守财务底座。销售网络仍是Amazon、天猫、京东店铺、Shopify和国内B2B。

留给阶段5的四项短板里，和本仓库直接相关的是两条：

1. **线下新零售触点空白。** 业务局限在线上和传统B2B，撑不起线下品牌体验、门店零售和到店履约。
2. **单仓辐射全国。** 只有深圳一个自营仓时，跨区发货又贵又慢；背景写20至30家门店落地后，区域补货也缺少就近仓。这是当时对开店之后的预期，不是已经开业的清单。

阶段4评估过中央订单路由，结论是先做ERP里的逻辑库存，中央路由留到阶段5，和区域仓、门店触点一起做。ERP仓库的一期范围仍然不含中央OMS和POS，见[待对齐事项A03](12.待对齐事项.md)。

### 2.3 阶段5（2023至2026年）：体验店、自提和上市审计同时到来

2023年营收突破8亿元，团队500多人，股改启动。门店侧新加上三件事。

**核心商圈开体验店。** 线上获客变贵，直播把品牌声量拉高，公司要用线下体验托住高客单。门店只有直营和加盟。加盟是代销，售出前货权在强盛。营业款由加盟门店向顾客收取，再经门店与总部结算归集到强盛。加盟店和直营店一样参与中央OMS的自提和代发。模式细则见[直营与加盟代销模式说明](7.直营与加盟代销模式说明.md)。

**小程序自提曾经不锁库存。** 2024年，一位顾客在微信小程序下单一套氮化镓充电套装，选深圳万象天地店自提。到店后，最后2件刚被进店顾客买走。小程序下单时没有锁定该店微仓。导购在工作群里联系附近仓补发，顾客等了3天，最终退款投诉。店长在周会上的原话是：线上卖出去的货，到店说没有，这不是新零售，这是砸招牌。

叙事里的改法是：顾客选门店自提时，中央库存立刻锁定该店微仓配额并生成动态提货码；到店后导购在POS扫码核销，微仓扣减并回传中枢。现场没有现货时，导购在POS代客下单，由就近自营区域仓发运，叙事里的承运是顺丰；业绩和提成计入该门店和导购工号。承运商是不是只有顺丰，见【待确认-47】。万象天地是这则叙事里的店名，不能据此列出全部门店，见【待确认-42】。

**部门利润口径对不上。** 2024年一次经营会上，新零售部门说线下门店单店全部盈利。财务把全公司账合完，综合净利率只有6.5%。差距里和门店有关的一条，是装修折旧没有进新零售自己的利润。阶段5要求门店利润含装修折旧，算法放在指标平台，不放在POS里重算。

同一阶段，主数据平台统一定义SKU、客户和组织，单向分发给ERP、POS、WMS、领星、聚水潭和金蝶。这是阶段5的目标架构。ERP一期的主数据仍在ERP里维护，见[待对齐事项A09](12.待对齐事项.md)。

## 三、四条业务线给门店的压力

渠道本身不都在POS里操作。下表只说明店为什么会被卷进履约。

| 业务线 | 阶段5叙事里的履约 | 对门店的压力 |
| --- | --- | --- |
| 跨境B2C | 国内头程到FBA，或欧美本地第三方仓 | 不走门店POS。它占用的是同一批成品库存 |
| 国内B2C电商和直播 | 东莞第三方电商仓、区域仓就近发货；直播现货与预售分流 | 大促和直播会抽走区域仓库存，门店要货和代发要看中枢还能不能锁到货 |
| 海外独立站 | 深圳仓直发为主，部分走第三方海外仓 | 不在本仓库。门店一期不做境外店 |
| 国内B2B批发 | 深圳仓整车出库或自提 | 代理商提货不是体验店收银。两套「自提」不要写成同一张单据 |
| 线下体验店 | 进店成交、小程序到店自提、缺货由区域仓代发 | 直营和加盟都进中央路由。微仓账面必须和锁库用同一本账 |

中央路由在叙事里按四个条件拆单：地址就近、运费最优、时效优先、库存充足。门店微仓是其中一类节点，和区域仓、东莞电商仓、海外仓、FBA并列。路由引擎不在POS里。

## 六、POS出现之前，店里实际怎么补这个坑

下面是自提锁库还没有接上时的跑法，不是目标态。

```plain
顾客在小程序选了一家店
    → 下单时没有锁定这家店的微仓
    → 进店顾客把最后几件买走
    → 导购到店发现没有货，到工作群里找附近仓
    → 顾客等待后退款
    → 业绩算给谁，群消息里对不上
```

目标态里，锁库和路由在中枢，POS只做核销、代客下单和店务回传。阶段5流程图如果读成「POS自己做出库记账」，以[待对齐事项A05](12.待对齐事项.md)为准。
