# 直营与加盟代销模式说明

> 更新日期：2026-10-15。
>
> 本文只说明两种门店在货、款、路由上已经确认的差别，以及哪些配置还没有数。字段、状态机和结算公式的展开放在后续目录。
>
> 公开品牌和软件手册里的比例，只说明市场上存在这种做法。强盛的比例、时限和金额一律用【待确认】编号，不把别人的数字抄进来。

---

## 一、只有两种店

| 模式 | 已经能确认的 |
| --- | --- |
| 直营 | 强盛自己经营。货权在强盛。顾客付款进入强盛的收款主体。门店微仓在强盛的逻辑库存里，并参与中央OMS的自提和代发 |
| 加盟 | 代销。售出前货权在强盛。营业款由加盟门店向顾客收取，再经门店与总部结算归集到强盛。加盟店参与中央OMS的自提和代发路由 |

阶段5背景原文写的是直营和联营体验店。现行口径只有直营和加盟，见[待对齐事项A01](12.待对齐事项.md)。正文不再使用联营门店、商场扣点、商场对账这套说法。

直营店如果租了商场铺位，并且租赁合同要求上传销售数据，POS按合同报送。报送不是第二种经营模式，也不改变货权和收款主体。哪些店有这个租约，见【待确认-02】【待确认-03】。加盟店进驻商场时是否也要报送，见【待确认-39】。

## 二、三条已确认口径怎么落到系统上

这三条是2026-10-15确认的，设计不能再做成可选开关。

### 2.1 货权在强盛

加盟店的库存记在强盛账上，进入中央一盘货。加盟商是保管人，不是买断之后的货主。

由此定下来的边界：

- 加盟要货审核通过后，是区域仓到该店库存的调拨，不产生货款，不做订货资金校验。
- 不设预付款、信用额度和先款后货。
- 售出前的盘亏发生在强盛的库存上。合理损耗由强盛承担，超出部分和保管不当由加盟商赔偿。百分比和计价见【待确认-23】。没有这个数之前，系统只保留共同盘点的事实，不自动算出赔偿。
- 退回区域仓走退仓，只转移库存位置，不因为退仓把货款退给加盟商。

建仓粒度建议是一店一仓，这样OMS才能按店锁定。若按加盟商合成一个仓，同一加盟商名下几家店就无法各自参与就近路由。这是建议，是否有加盟商要求合并，见【待确认-22】。

### 2.2 营业款由门店收取，再结算归集

加盟店POS照常收款。日结封账之后，中枢按营业日生成应缴营业款。分成或返点放在结算单里，和上缴情况一起结清。

由此定下来的边界：

- 应缴对应这家店向顾客收的销售净额，按支付方式分开。线上已经付款、只到店核销或由本店代发的订单，钱不进这张应缴单。
- POS不让店员在日结时自行扣下分成。分成等结算单。
- 结算单取已经封账的流水。异议另提，不改原始成交。
- 往来上需要能看见应缴未缴、应付给加盟商的分成、赔偿和保证金。这笔账放在中枢还是金蝶，见【待确认-38】。

仍要单独决定的，见【待确认-16】至【待确认-19】：收款用强盛的商户号还是加盟商的商户号，上缴是全额还是净额，分成按营业额、返点还是供货价，结算周期多长。

全额上缴、再由强盛按周期支付分成，是便于退货和盘亏都落在同一张结算单上的做法。它仍然是建议，不是已经确认的上缴方式。

### 2.3 参与自提和代发路由

加盟店的代销仓和直营微仓一样，可以被中央OMS锁定。单店因为盘点或停业临时不接单，用门店自己的停接开关，不改合同上的「参与路由」。

由此定下来的边界：

- 顾客选加盟店自提时，锁的是该店代销仓，不是加盟商名下的一个总数。
- 线上订单的营业款不经过门店。履约之后只记佣金。佣金按单还是按金额、何时计提，见【待确认-20】。
- 门店拒单不记佣金。拒单之后由OMS改派。频繁拒单要不要扣分，背景没有写，不在本期规则里自定惩罚。
- 核销不在加盟店再收一次线上已经收过的钱。

## 三、两种店对照

| 事项 | 直营 | 加盟（代销） |
| --- | --- | --- |
| 货权 | 强盛 | 强盛。已确认 |
| 库存位置 | 门店微仓 | 代销仓，记在强盛账上。粒度见【待确认-22】 |
| 顾客付款 | 强盛收款主体 | 门店先收，再结算归集。商户号见【待确认-16】 |
| 要货 | 申请后调拨 | 同一条调拨，不产生货款。铺货额度见【待确认-24】 |
| 日结之后 | 收银对账 | 中枢生成应缴营业款 |
| 结算 | 无加盟结算单 | 分成或返点、履约佣金、退货冲回、盘亏赔偿、未缴营业款。口径见【待确认-18】【待确认-19】 |
| 价格 | 统一零售价，改价走授权 | 同样由强盛定价。价格带见【待确认-34】 |
| 谁经营 | 强盛员工 | 加盟商自营、强盛派店长或托管，见【待确认-35】 |
| 路由 | 参与 | 参与。已确认 |
| 开票 | 强盛 | 强盛开还是加盟商开，见【待确认-31】 |
| 数据范围 | 按授权看店 | 加盟商只看本加盟商 |

经营权会影响店员账号和提成由谁发放，见【待确认-36】。它不改变货权和路由。

## 四、退换货在两种店之间

本店买、本店退：在本店验货，按原收款路径退，库存回到本店，分成若已计提则冲回。冲回的时点见【待确认-13】【待确认-28】。

跨店退，包括直营和加盟之间、两家加盟店之间：技术上必须从原来的收款商户号退回。是否对顾客开放，见【待确认-27】。背景没有写「已经开放」。

线上订单到店退：门店验货，不经手那笔线上的钱，退款由中枢按原渠道退。是否冲回履约佣金、门店有没有受理费，见【待确认-29】。

质量问题的天数，见【待确认-30】。不能把其他品牌公开的7天、30天写成强盛的期限。
